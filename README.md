## 🚀 Overview

**NewsFit44** is a modern web application built using Flask that provides users with a personalized news experience along with account management features.

It includes:

* 📊 Dashboard analytics
* 📰 News feed system
* 👤 User profile management
* 🔔 Notification settings

---

## ✨ Features

* 🔐 User Authentication (Register & Login)
* 📊 Dashboard with user insights (reads, skips, interests)
* 📰 News browsing with read/skip options
* 🔔 Notification preferences management
* 👤 Profile editing and settings
* 🎨 Clean and responsive UI

---

## 🧱 Tech Stack

* **Backend:** Flask (Python)
* **Frontend:** HTML, CSS
* **Database:** SQLite (`database.db`)
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/hemapoojari/newsfit44.git
cd newsfit44
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Application

```bash
python app.py
```

### 4️⃣ Open in Browser

```
http://127.0.0.1:5000
```
